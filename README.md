# Javascript Frameworks Course Assignment

## Description
This is my Javascrip Framework Course Assignment. In this app, i have created
an online shop using next.js.

## How to use
- Click on a product to check out it's unique product page

- Use the searchbar on the landing page to search for a single products

- On the product page add the product to the cart with the click of a button

- On the cart, update quantity on each product using buttons on each section for the products

- Remove products from the cart. 

- Send a message with the contact form

- Contact page can be reached by clicking on "contact us" in the footer.

- Logo is a link to the landing page

- Toggle light/dark mode with the toggler in the navigationbar

- link to cart page is the cart icon on the navigationbar

- Open menu with the burger-menu icon on top left when using a mobile device.

- Confirm "purchase" by clicking purchase-button on the checkout page.

- When confirming checkout, the user will be taken to the landing page.
